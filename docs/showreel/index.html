New in 0.36

Everything that shipped since 0.35.

  • QuorumSeveral agents vote on a worker's result; only what a majority accepts is merged.
  • Review mapA heat map of the whole change, coloured by what deserves your attention.
  • Live reviewThe git button opens the review beside the agent, with commit and push below.
  • Hosts in one windowThis computer and SSH servers side by side, each with its own section.
  • Sticky notesLeave yourself notes on a session. They are never sent to the agent.
  • Real costWhat each session and task cost, from the transcript, compared by profile.
  • Record a bugYour clicks and errors are logged with the screen, never what you type.
  • Mistral VibeA ninth agent, and any missing agent CLI installs from the app.
  • Lid closedKeep agents running while the laptop is closed, on Linux, macOS and Windows.
  • SubjectsSort a workspace's sessions by sub-folder or git submodule.
  • Profiles by task typeA bug fix and a migration in the same repo start with different models.
  • Agents file tasksWhat an agent finds along the way lands on the board, or it fixes it itself.
